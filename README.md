RinType — 中英文文案自动检查工具

为 Figma 文本严格把关：中英文混排、标点、大小写、千分符、单位写法等，
帮你一键发现并修复设计稿里的低级错误，让出图更专业。

━━━━━━━━━━━━━━━━━━━━━━

🎯 它检查什么

• 空格与间距 —— 中英文/中数字之间空格、URL 前后空格、运算符两侧空格
• 大小写 —— iOS / GitHub / JavaScript 等通用专有名词
• 品牌术语 —— BitMart / USDT / DeFi / NFT / Web3 / MetaMask 等官方写法
• 标点符号 —— 中英文标点自动对应（，↔, 。↔.），括号按内容判断全/半角
• 数字与货币 —— 千分符、货币符号位置、百分号紧贴、±符号顺序
• 单位 —— 时间单位（y/M/d/h/m/s）、计量单位（K/M/B）大小写规范
• 字符规范 —— 全角字母数字自动转半角
• 英文拼写 —— 常见高频错拼（recieve / seperate / occured 等）
• 连字符与破折号 —— 中文语境自动用 ——，英文连字符保留

━━━━━━━━━━━━━━━━━━━━━━

🛡 智能跳过，减少误报

• URL 链接内部所有规则自动跳过，绝不改坏链接
• Order ID / 邀请码等纯数字标识符自动豁免千分符（支持跨图层识别）
• 日期格式（2016-01-01）不会被当成减法运算
• 隐藏图层、TITLE / UPPER 文本自动跳过
• 域名、邮箱地址中的术语不会被改写

━━━━━━━━━━━━━━━━━━━━━━

🚀 怎么用

1. 选中要检查的内容
   可以是画板（Frame）、组（Group）、组件，或直接选文字图层

2. 运行插件
   Plugins → RinType（或在画布右键 → Plugins → RinType）

3. 查看并修复
   • 插件自动扫描并列出所有发现的问题
   • 点单条「修复」一键替换
   • 不想改的点「跳过」
   • 支持按规则类别筛选
